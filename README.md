# 猫咪小院

面向手机和电脑浏览器的温暖养猫小游戏。创建自己的第一只猫，留下食物和玩具吸引流浪猫，培养信任后邀请它们成为家人。

## 运行

直接打开 `index.html` 即可游玩。无需构建、安装依赖或注册。也可以使用任意静态网页服务器运行此目录。若托管到 GitHub Pages，手机和电脑即可通过同一网址打开。

## 玩法

- 点击猫咪，喂食或摸摸；每分钟记一次陪伴。
- 来访猫信任达到 100 后可以收养并起名。
- 在「布置小院」解锁或摆放 12 件物品，用不同物件吸引不同喜好的猫咪。
- 离线每半小时积累 3 枚猫爪印，最多结算 12 小时。没有签到惩罚，定居猫不会离开。
- 查看猫咪档案与回忆册，按自己的节奏长期游玩。

## 存档

进度保存在当前浏览器。换设备、切换网址或清除浏览器数据前，请在页面底部导出存档，到另一个浏览器导入。浏览器不能写入存档时会提示。外部字体加载失败时使用系统字体，玩法无网络依赖。

## 验证

`node --test game.test.cjs`

规则涵盖自定义、离线奖励上限、时钟倒退、互动冷却、收养、购买、存档迁移与来访上限。
