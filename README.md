# 家

面向手机和电脑浏览器的全屏养猫小游戏。日系 Q 版插画场景充满整个页面，小猫用独立动作帧自主四脚行走、转身、眨眼、舔爪和打盹。创建自己的第一只猫，吸引流浪猫，培养信任后邀请它们成为家人。

## 探索家园

使用底部地图切换阳光小院、花香阳台、暖暖客厅、午睡卧室、暖暖厨房和猫窝房。小院的房门可以点击进入卧室，小木屋可以进入猫窝房；室内房门返回小院。每只猫只在一个房间里，位置随存档保留。定居猫约每 1.5–3 分钟自主换一个地方，来访猫留在院子里。房间入口显示猫咪数量，猫咪列表中可以查看所在房间并跳转；召唤只招呼当前场景的小猫。

猫咪有 10 种品种、14 种毛色、8 种花纹选择，品种和毛色分开保存。长毛、短毛和绒毛猫使用不同的动作素材。每个动作图集包含 8 帧行走以及站立、眨眼、舔爪、睡觉与坐姿。画面使用用户确认的日系 Q 版插画风格，静态场景缓存后叠加独立猫咪，限制毛色帧缓存大小。素材加载失败时使用原有程序绘制画面，玩法不受影响。

场景包含屋顶、窗帘、树木、花盆、围栏、石板小径、阳台花架、客厅沙发与壁炉、床与被褥、床头灯、书架、厨房橱柜、水槽、炉灶、冰箱、餐桌、猫爬架和多个猫窝。装饰购买后以场景物件呈现，养成列表通过浮层打开。

## 运行

无需构建、安装依赖或注册。运行 `node server.cjs`，打开 `http://127.0.0.1:4173/`，或使用 GitHub Pages 网址。请通过 HTTP 服务游玩，直接打开本地 HTML 可能受浏览器的 Canvas 安全策略限制。

## 玩法

- 点击场景中移动的小猫，喂食或摸摸；每分钟记一次陪伴。
- 流浪猫没有名字和场景名牌，列表以「流浪小猫」描述；信任达到 100 后必须填写非空名字才完成收养，并显示名牌。
- 旧存档的来访猫自动清除旧昵称；已收养小家人的名字、进度和位置保留。
- 在「布置小院」解锁或摆放 12 件物品，用不同物件吸引不同喜好的猫咪。
- 离线每半小时积累 3 枚猫爪印，最多结算 12 小时。没有签到惩罚，定居猫不会离开。
- 查看猫咪档案与回忆册，按自己的节奏长期游玩。

## 存档

进度保存在当前浏览器。换设备、切换网址或清除浏览器数据前，请在右上角设置中导出存档，到另一个浏览器导入。浏览器不能写入存档时会提示。外部字体加载失败时使用系统字体，玩法无网络依赖。

## 验证

`node --test`

规则涵盖自定义、离线奖励上限、时钟倒退、互动冷却、非空名字收养、购买、存档迁移、来访上限、唯一位置、动画帧、场景裁切与毛色转换。
