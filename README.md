# 猫咪小院

面向手机和电脑浏览器的全屏养猫小游戏。手绘风格场景充满整个页面，小猫以程序绘制并通过四条腿的关节动画自主行走、转身、摆尾、眨眼、打盹。创建自己的第一只猫，吸引流浪猫，培养信任后邀请它们成为家人。

## 探索家园

使用底部地图切换阳光小院、午睡卧室、暖暖厨房和猫窝房。小院的房门可以点击进入卧室，小木屋可以进入猫窝房；室内房门返回小院。每只猫只在一个房间里，位置随存档保留。定居猫约每 1.5–3 分钟自主换一个地方，来访猫留在院子里。房间入口显示猫咪数量，猫咪列表中可以查看所在房间并跳转；召唤只招呼当前场景的小猫。

猫咪采用柔和毛色渐变、圆脸、短腿、眼睛高光和自然趴睡造型。场景加入纸张质感、暖光、藤蔓、串灯、花丛和室内装饰；静态场景缓存后再叠加动态猫咪，减少每帧重复绘制。

场景包含屋顶、窗帘、树木、花盆、围栏、石板小径、床与被褥、床头灯、书架、厨房橱柜、水槽、炉灶、冰箱、餐桌、猫爬架和多个猫窝。装饰购买后以场景物件呈现，养成列表通过浮层打开。

## 运行

直接打开 `index.html` 即可游玩。无需构建、安装依赖或注册。也可以运行 `node server.cjs`，打开 `http://127.0.0.1:4173/`。若托管到 GitHub Pages，手机和电脑即可通过同一网址打开。

## 玩法

- 点击场景中移动的小猫，喂食或摸摸；每分钟记一次陪伴。
- 来访猫信任达到 100 后可以收养并起名。
- 在「布置小院」解锁或摆放 12 件物品，用不同物件吸引不同喜好的猫咪。
- 离线每半小时积累 3 枚猫爪印，最多结算 12 小时。没有签到惩罚，定居猫不会离开。
- 查看猫咪档案与回忆册，按自己的节奏长期游玩。

## 存档

进度保存在当前浏览器。换设备、切换网址或清除浏览器数据前，请在右上角设置中导出存档，到另一个浏览器导入。浏览器不能写入存档时会提示。外部字体加载失败时使用系统字体，玩法无网络依赖。

## 验证

`node --test game.test.cjs`

规则涵盖自定义、离线奖励上限、时钟倒退、互动冷却、收养、购买、存档迁移与来访上限。
